           CFC 足球职业生涯模拟器 - 使用说明（V2.3.0 测试版）

【这是什么】
- 一款中国足球题材的单机职业生涯模拟游戏（V2.3.0 测试版 · 2026赛季版）。
- 16 岁从俱乐部 U17 梯队起步，走完 U19 → U21预备队 → 一线队 →
  留洋欧洲 → 国家队的完整阶梯，赶上一个真实的世界杯周期：
  2027亚洲杯(沙特) · 2028洛杉矶奥运会 · 2027-2033世预赛 ·
  2030世界杯(西葡摩) · 2034世界杯(沙特)。
- 最终目标：成就一条史无前例的中国巨星之路（金球奖/欧冠/世界杯）。
- 支持 3 个本地存档槽，进度自动保存。
- 多端形态：电脑端（根目录 exe / 启动游戏-浏览器版.bat / 桌面窗口版.bat）
  与手机端（发布-安卓/CFC足球生涯（测试版）-V2.3.0.apk），内容完全一致。

【文件说明】
- CFC足球职业生涯模拟器.exe : Windows 单机版（推荐，双击即玩）
- football-career-simulator.html : 游戏源文件（浏览器直接打开，
  亦是安卓版唯一源码：改动后运行 mobile/sync.py 同步进安卓工程）
- assets/ui/ : 界面标志与应用图标（logo.ico）
- assets/logos/ : 球队队徽与联赛标志（147 队 + 15 联赛）
- football-career-simulator.html.v1.bak : V1.5 备份
- build/revamp/ : V2.0 样式与脚本源码（css.css / js1-js5.js /
  body.html / assemble.py 组装脚本 / check_syntax.py 语法审计）
- build/cfc_game_app.py : exe 启动器（pywebview）
- run_game.py + start.bat / start.sh : 网页版启动脚本（需 Python 3）
- mobile/ : 安卓工程（Capacitor 7，应用名" CFC足球生涯（测试版）"）
  · sync.py : 把 HTML+assets 同步进安卓工程（改完 HTML 必跑）
  · tools/ : 资源优化/图标生成/横屏截图脚本
  · android/ : 原生工程（Gradle 构建 APK/AAB；签名配置见
    keystore.properties，密钥文件已单独备份，切勿入库）
  构建命令（需 JDK 21 + Android SDK）：
    cd mobile/android && gradlew assembleRelease   → APK
    cd mobile/android && gradlew bundleRelease     → AAB

【如何游玩】
方式一（推荐，不受任何拦截）：双击「启动游戏-浏览器版.bat」
  - 用默认浏览器打开游戏，内容与 exe 完全一致，进度自动保存
方式二：双击「CFC足球职业生涯模拟器.exe」
  - 首次运行如被 Windows 拦截，见下方【常见问题】
  - 显示 CFC 启动动画，进入主界面后
    「新游戏 → 填写球员信息 → 选择存档槽」即可开始
  - 存档保存在本机 WebView 数据目录，重启不丢档
方式三：双击 football-career-simulator.html 用浏览器打开
方式四：运行 start.bat（Windows）或 ./start.sh（macOS/Linux）
方式五（安卓手机）：安装 CFC足球生涯（测试版）.apk（手机横屏游玩）
  - 存档保存在应用数据目录 + 原生 Preferences 双备份
  - 卸载应用会删除存档，换机前请先截图记录生涯进度

【游戏内操作】
- 左侧导航：剧情（主线）/ 成长（属性+梯队链）/ 数据（赛季+生涯）/
  荣誉（奖杯墙）/ 履历（生涯大事记）
- 剧情页底部有「快进 · 跳过剩余剧情直接结算」，可一键打完一个赛季
- 游戏中按 ESC 或点击右上角「菜单」：保存/读取/管理存档/退出
  （桌面版"退出游戏"会直接关闭整个程序）
- 快捷键：Ctrl+S 快速保存

【常见问题】
Q：双击 exe 提示"智能应用控制已阻止可能不安全的应用"（无法验证发布者）？
   原因：Windows 智能应用控制（Smart App Control）处于开启状态时，会拦截
   一切没有数字签名的程序——与游戏新旧版本无关（本机检测：策略状态=开启），
   最新版 exe 同样会被拦，且这种弹窗没有"仍要运行"按钮。解决办法：
   1. 【最简单，推荐】改玩浏览器版：双击「启动游戏-浏览器版.bat」，
      内容与 exe 完全一致，不受任何拦截；
   2. 关闭智能应用控制后再运行 exe（二选一）：
      a) 双击「关闭智能应用控制-管理员运行.bat」，按提示授权并重启电脑；
      b) 手动：设置 → 隐私和安全性 → Windows 安全中心 → 应用和浏览器控制
         → 智能应用控制设置 → 关闭。
      注意：该功能一旦关闭，通常需要重装/重置 Windows 才能重新开启；
   3. 若拦截弹窗是"Windows 已保护你的电脑"（右下角有"仍要运行"按钮，
      属于 SmartScreen，与上面不是同一机制）：点"更多信息 → 仍要运行"，
      或右键 exe → 属性 → 勾选"解除锁定"。
   注：请始终运行本目录（CFC2.0 根目录）下的最新版 exe；旧版本子文件夹
   （如 CFC1.0）中的拷贝已过期，请删除或勿再使用。
