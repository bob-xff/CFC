             CFC 足球职业生涯模拟器 - 使用说明
=================================================================

【这是什么】
- 一款中国足球题材的单机职业生涯模拟游戏（V1.5）。
- 从 16 岁中超青训开始，经历预备队、一线队、留洋、国家队，
  最终走向传奇；含训练、比赛、社交、媒体、转会、世预赛等剧情。
- 支持 3 个本地存档槽，进度自动保存。

【文件说明】
- CFC足球职业生涯模拟器.exe : Windows 单机版（推荐，双击即玩）
- football-career-simulator.html : 游戏源文件（浏览器直接打开）
- CFC--logo文件/ : 你的官方标志六件套（启动页/标准/白底/黑底/反白/透明底）
- assets/ui/ : 界面使用的标志版本与应用图标（logo.ico）
- assets/logos/ : 球队队徽与联赛标志（147 队 + 15 联赛，含中超/中甲/欧洲/日韩/南美/北美/西亚）
- build/style_new.css : 界面视觉样式源码（已内嵌进 HTML）
- build/cfc_game_app.py : exe 启动器（pywebview）
- build/download_logos.py : 队徽下载脚本（GitHub + TheSportsDB + API-Football）
- run_game.py + start.bat / start.sh : 网页版启动脚本（需 Python 3）

【如何游玩】
方式一（推荐）：双击 CFC足球职业生涯模拟器.exe
  - 打开程序后首先显示 CFC 启动动画（启动页标志 + 加载进度条）
  - 存档保存在本机应用数据目录，重启/移动 exe 不丢档
方式二：双击 football-career-simulator.html 用浏览器打开
方式三：双击 start.bat（Windows）或运行 ./start.sh（macOS/Linux）

【游戏菜单】
- 游戏中按 ESC 或点击右上角「菜单」打开游戏菜单
- 支持：保存游戏 / 保存并退出到存档页 / 读取存档 / 管理存档 /
        退出到主菜单 / 退出游戏
- 快捷键：Ctrl+S 快速保存

【设计说明】
- 视觉参考 EA FC / Football Manager 等主流足球游戏：
  深色近黑海军蓝 + 单一"绿茵绿"强调色，扁平化、少渐变、低视觉疲劳
- 界面无 emoji，全部使用统一线性 SVG 图标
- 中超 16 队 / 中甲 12 队均为当前真实俱乐部名单
- 收入机制贴合中国足球现状：中超国内球员顶薪 300 万人民币/年（限薪），
  中甲顶薪约 100 万人民币/年
- 每个赛季自动模拟全赛季数据（出场/进球/助攻/评分/最佳/零封/关键传球/抢断等），
  剧情选择在模拟基础上叠加，不再出现"一赛季只进一两个球"的情况
- 转会市场覆盖欧洲 / 南美 / 北美 / 东亚 / 西亚；合同到期必须续约或转会，
  也可主动寻求转会
- 联赛与洲际规则按最新现实设定：中超/日韩/西亚打亚冠精英赛、中甲不打洲际、
  巴阿打解放者杯、欧洲打欧冠；杯赛名称按所在国显示（足协杯/天皇杯/足总杯等）
- 全真实人员设定：150+ 支球队配置真实核心球员（武磊、姆巴佩、萨拉赫、梅西等），
  剧情中的球员全部为真实姓名或角色称谓，无虚构人名
- 数据模型参考 EA FC：青训初始能力回归真实、按年龄/位置分项涨跌
  （28 岁后速度与身体下滑、技术更持久）、出场次数按梯队决定

【重新打包 exe（可选）】
1. 安装 Python 3.10+
2. pip install pywebview pyinstaller
3. 进入 build 目录执行：
     pyinstaller --noconfirm --onefile --windowed --name "CFC足球职业生涯模拟器" ^
       --icon ..\assets\ui\logo.ico --add-data "..\football-career-simulator.html;." ^
       --add-data "..\assets\logos;assets\logos" ^
       cfc_game_app.py
4. 生成的 exe 位于 build\dist 下
